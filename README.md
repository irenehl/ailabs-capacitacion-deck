# Ai Labs · Capacitación en IA para equipos

Presentación comercial animada de los programas de capacitación de [Ai Labs](https://www.ailabs.sv/).

**Ver en línea:** https://irenehl.github.io/ailabs-capacitacion-deck/

## Uso

Abrí `index.html` en el navegador.

| Acción | Tecla |
| --- | --- |
| Siguiente | `→` `Espacio` `Enter` o clic |
| Anterior | `←` o clic en el borde izquierdo |
| Pantalla completa | `F` |
| Ir a una slide | `index.html#5` |

## Exportar a PDF

```bash
npm install
npx playwright install chromium
npm run pdf          # genera AiLabs-Capacitacion-IA.pdf
npm run screenshots  # además guarda capturas en .render/
```
